Privacy & credits.

What this portal does

This is a static project portal hosted on GitHub Pages. The portal code contains no analytics, advertising, account system or tracking cookies. GitHub, as the hosting provider, processes requests according to its own policies. See GitHub’s privacy statement.

The motion control stores one preference, prl:motion, in your browser’s local storage. The portal still works when storage is unavailable. You can remove this preference by clearing this site’s browser data.

Projects and embedded previews

The portal requests public project metadata and thumbnail images from the addresses listed in the project registry. Those hosts receive the usual network request information, including an IP address. An interactive preview is loaded only when you choose “Load interactive preview”. It runs in a sandbox without microphone, camera, MIDI or geolocation permission. Full project applications open as separate pages and have their own behaviour and privacy implications.

Optional microphone

The light field uses pointer or touch input without recording it. The optional microphone mode starts only after you press “Enable microphone” and grant browser permission. Web Audio analyses short-lived buffers locally to animate the ribbons; the portal does not record, store, upload or play back microphone audio. A live indicator and Disable microphone control remain visible. Pausing motion, scrolling the field offscreen, switching tabs or leaving the page stops the tracks and closes the audio context. It does not restart automatically. A cancelled or timed-out permission request cannot activate late.

The light field is an artistic response, not a calibrated measurement. Project preview graphics should not be interpreted as measured research data unless the project explicitly identifies them as such.

Event listings

Events are served as a local JSON file. When an external public CSV or JSON feed is configured, the publishing workflow fetches it on the server side. Visitors do not connect to Google Sheets to read events. Only public event information belongs in that feed. If a refresh fails, the local saved listings are displayed with a notice.
